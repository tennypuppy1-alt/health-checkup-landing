# 건강검진 랜딩 페이지

건강검진 안내용 간단한 단일 페이지(랜딩 페이지) 예제입니다.

## 구성

- `index.html` : 페이지 전체(HTML, CSS, JavaScript 포함)

## 페이지 내용

- 소개 및 예약 문의 버튼
- 검진 프로그램 안내 (기본 / 종합 / 맞춤)
- 검진 진행 순서
- 예약 문의 폼

## 사용 방법

`index.html` 파일을 브라우저에서 열면 바로 확인할 수 있습니다. 별도 설치나 빌드는 필요하지 않습니다.

## 참고

- 문의 폼은 데모용이라 입력 내용이 서버로 전송되지 않습니다.
- 검진 항목과 비용은 예시이며, 실제 사용 전에 의료광고 심의 기준에 맞는지 검수가 필요합니다.
